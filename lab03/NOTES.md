git diff - сравнивает версии и что сделано

git show - показывает то, что сделано в последнем коммите

git log - показывает историю коммитов

log -S - ищет изменения в истории коммитов и показывает, что было изменено в каждой версии

blame - показывает кто и в каком файле что-то менял и все изменения

git revert - создает новый коммит, отменяющй старый, но не удаляет ошибочный

git reset --hard - переводит на предыдущий коммит и удаляет ошибочный
