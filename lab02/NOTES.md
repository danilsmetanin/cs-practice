рабочая папка - папка с которой связан гит и идет работа в текущий момент, в ней будут сохраняться версии

индекс - файлы, которые попадут в коммит

коммит - сохранение версии локально

github - хранилище и для совместной работы

git - контроль версий, локально

git diff - сравнение версий и показ изменений, которые не добавлены 

git diff --staged - показ содержимого, что попадет в коммит
