# Git: основные понятия

## Рабочая папка

Рабочая папка — это папка проекта, в которой я создаю и изменяю файлы. Git видит эти изменения и показывает их в статусе.

## Индекс

Индекс — это промежуточная область между рабочей папкой и коммитом. В неё попадают файлы после `git add`. Из индекса изменения попадают в следующий коммит.

## Коммит

Коммит — это сохранённая версия файлов проекта в истории Git. У коммита есть сообщение, автор и уникальный хеш.

## Git и GitHub

Git — это программа контроля версий, которая работает локально на компьютере. GitHub — это сайт для хранения удалённых репозиториев и совместной работы. Git можно использовать без GitHub, а GitHub работает с репозиториями Git.

## Использованные команды

- `git status` — показывает состояние рабочей папки и индекса.
- `git diff` — показывает изменения в файлах, которые ещё не добавлены в индекс.
- `git diff --staged` — показывает изменения, которые уже добавлены в индекс и попадут в следующий коммит.
